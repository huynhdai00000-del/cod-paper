# What `build_test_set` draws, and whether `T1_in_distribution` is true

Generated by `audit_port/scripts/21_test_set_provenance.py`. Training population: 300 cases from the frozen realistic sampler (`example_cod_seed1.yaml`, distribution hash `fc4cb76c3b32ec17`). Test population: the 100-case seed-999 benchmark as `scripts/run.py` builds it.

## 1. What it draws

`build_test_set` does not consult `distribution.sampler` at all. It calls `profiles.sample_consistent_ic` — the **v57-era** IC sampler, the one audit M-9 is against — and then builds its own two waveform families in line, hardcoded:

| half | IC | load | ambient |
|---|---|---|---|
| CK, cases 0-49 | `sample_consistent_ic` | `K ~ U(0.4, 1.4)`, constant | `Ta ~ U(15, 45)`, constant |
| TV, cases 50-99 | `sample_consistent_ic` | `K + 0.2 sin(2 pi t / TW)` | `Ta + 5 sin(2 pi t / TW + pi/3)` |

The only thing the config reaches is the IC formula: `run.py` reads `distribution.steady_state_formula` and passes `true_fixed_point_np` (the frozen config) or `formula_A` (v57). Everything else — the load families, the amplitudes, the period, the IC construction — is fixed in the source of `build_test_set` and `sample_consistent_ic`, neither of which is inside the hashed `distribution` block.

So the sampler that fix 7 and fix 9 built, froze and hashed drew the **training** data only. The evaluation ran on the distribution those fixes were made to replace.

## 2. Which of the two benchmarks a run.json came from

Both IC formulas replay the same 100 draws, so they differ only through `theta_TO(0)` and the gas ICs derived from it. `denominator_median` is a property of the ground truth alone, so it fingerprints the test set without needing the model:

| state | `steady_state_formula: true_fixed_point` | `formula_A` (v57) |
|---|---|---|
| `theta_TO` | 33.6774 | 32.9834 |
| `c_H2` | 0.0223299 | 0.0184922 |
| `c_C2H2` | 0.00153704 | 0.000672627 |
| `c_C2H4` | 0.00915019 | 0.00709916 |
| `c_CO` | 0.0260262 | 0.0229085 |
| `c_CO2` | 0.0395906 | 0.0345726 |

The frozen config sets `steady_state_formula: true_fixed_point`, so a run off `example_cod_seed1.yaml` reports the left column. `PHASE1_VERIFICATION.md` reproduces v57 and reports the right one. The difference is Phase 2 fix 1, not a different draw and not a different sampler: formula A sits up to 23.8 degC below the true fixed point, which moves every `theta_TO(0)` and, because `c_eq` is exponential in temperature, every gas IC with it.

## 3. Is the tier label true?

Each axis compares the seed-999 benchmark against the frozen training sampler. `OUT` means the benchmark is outside what the model was trained on.

| axis | verdict | measurement |
|---|---|---|
| theta_TO(0) range | **OUT** | test [21.4, 150.0] vs train [38.7, 115.8] degC; 20% of test cases outside |
| IC consistency with the profile | **OUT** | |theta_TO(0) - eq(K(0),Ta(0))| median test 24.82 vs train 3.76 degC (ratio 6.6x) |
| mean hot-spot inside the sampler's operating band | **OUT** | training clips the drawn hot-spot to [62, 122] degC; 37% of test cases have a window-mean hot-spot outside it (test range [39.4, 235.1]) |
| realised hot-spot swing | inside | median test 21.85 degC vs train 11.20 (train p5-p95 3.32-31.97); 28% of test cases above train p95 |
| K range | **OUT** | test [0.305, 1.399] vs train [0.323, 1.397] |
| load cycle period | **OUT** | training day is 1440 min (fix 7, N-6); the test TV branch completes a whole cycle inside the 720 min window, i.e. a 720 min load period (100% of TV cases return to K(0) at the window end) |
| ambient swing | inside | median test 2.50 degC vs train 4.29; test CK half is flat by construction (50% of test cases have zero ambient variation) |
| gas ICs above IEC 60599 attention | **OUT** | test 46.0% vs train 9.3% |
| ICs above the physics-loss state clamp | **OUT** | test 30.0% vs train 1.0% |

**7 of 9 axes fall outside the training distribution.**

## 4. Verdict

`T1_in_distribution` is **not** a true description of this evaluation. The model was trained on the fix-7 realistic sampler and scored on the v57-era benchmark, which differs from it on the axes above — including two hard support boundaries the training sampler enforces by construction (the hot-spot operating band, and the profile-consistent IC). That is a train/test distribution mismatch of the same kind the freeze work exists to prevent, and it is worse than the original in one respect: the original was mislabelled in the manuscript, this one is mislabelled in the config, where the protocol reads it.

Consequence for O-5's numbers: they are not wrong, they are **unlabelled**. theta_TO MAE 1.072 degC is an out-of-distribution figure being compared against v57's 0.399 degC, which was an in-distribution figure for v57's own training set. The comparison measures distribution shift and physics fixes at the same time and cannot separate them.
